- В коммитах и PR не упоминать Claude: ни Co-Authored-By, ни «Generated with».
- Во время работы не писать промежуточных сообщений — только итог в конце.
- Если dev-сервер ведёт себя странно (старый код после правки общего модуля), перезапустить `npm run dev`.
