# Handoff: Kuznetsovs Gallery — сайт, админ-панель, 404

## Обзор
Редизайн kuznets.uz: сайт галереи принт-картин из Ташкента (каталог, карточка работы, заявка) и отдельная админ-панель для заявок, каталога, цен, отзывов и аналитики. Плюс интерактивная страница 404.

## О файлах в этом пакете
Файлы `*.dc.html` — **дизайн-референсы в HTML**: прототипы, показывающие точный вид и поведение. Это **не продакшн-код**. Задача — **пересобрать эти экраны в реальном проекте** на выбранном стеке, используя его паттерны. Готового кодового проекта нет, поэтому рекомендуемый стек:

- **Next.js 15 (App Router) + TypeScript**
- Стили: CSS Modules или Tailwind, с токенами из раздела «Дизайн-токены» как CSS-переменными
- БД: PostgreSQL + Prisma (или Supabase)
- Авторизация админки: серверная (сессия в httpOnly-cookie). Сейчас в прототипе она фейковая.
- Картинки: `next/image`. Каталог сейчас ссылается на `https://kuznets.uz/wp-content/uploads/…`.

Открыть прототипы локально: `npx serve .` в этой папке, затем `/Kuznetsovs Gallery.dc.html`, `/Admin.dc.html`, `/404.dc.html`. Нужен именно http, а не file://, иначе не загрузится `data/products.json`.

## Точность
**High-fidelity.** Цвета, шрифты, отступы, анимации и тексты финальные, повторять пиксель в пиксель. Все бывшие «твики» зафиксированы константами (см. «Настройки»).

## Экраны — сайт (`Kuznetsovs Gallery.dc.html`)
Одностраничный прототип с роутингом в state (`page: home | catalog | work | info`, сохраняется в `kz_route`). В Next.js — роуты `/`, `/collection/[category]`, `/work/[code]`, `/info`.

### Шапка
- **≥960px (classic):** sticky, glass-фон. Сетка `auto 1fr auto`. Логотип 40px (при скролле >40px — 30px, отступ 16→8px, transition .35s). Навигация пилюлями 14/500, padding 8×14; активный пункт — фон ink, текст paper; у «Коллекции» рядом mono-счётчик 10px. Справа: ThemeToggle «scene», телефон (mono 13), кнопка «Заявка N» (фон accent, при hover — ink).
- **<960px (новая мобильная/планшетная):** flex space-between, padding 12px gutter.
  - Логотип: 34px; <600px — 28px.
  - Справа ThemeToggle, кнопка заявки: ink-пилюля 38px, иконка сумки и счётчик; текст «Заявка» только ≥600px.
  - Кнопка меню (44px по высоте). Текст «Меню»/«Закрыть» — стопка из 2 строк в окне высотой 1em, translateY 0 → −50%. Открытие .6s cubic-bezier(.22,1,.36,1), закрытие .45s (.76,0,.24,1). Текст скрыт <380px.
  - Иконка 24×24: две линии 1.5px, закрытое состояние translateY(∓4px). Открытое: rotate(±45deg) → крестик, .5s (.22,1,.36,1); обратно .35s (.76,0,.24,1).

### Меню (по мотивам React Bits «Staggered Menu»)
Fixed-оверлей под шапкой (z 29, шапка z 30). На время открытия у `html` ставится `overflow:hidden`.
1. Два слоя на весь экран (ink, затем accent): translateX(100%) → 0, 500ms, задержка i×70ms, ease (.22,1,.36,1).
2. Панель (paper): с задержкой 150ms, 650ms, тот же ease.
3. Пункты «главная / коллекция / покупателям / контакты» — clamp(46px,12.5vw,104px), 600, −.065em. Каждый пункт в обёртке с overflow:hidden, сама надпись идёт от translateY(140%) rotate(10deg) к none. 1000ms, старт = панель + 97ms, шаг 100ms. Текущий раздел окрашен accent, hover — accent.
4. Номера 01–04: mono 13, accent, opacity 0→1, 600ms, на 100ms позже пунктов, шаг 80ms.
5. Блок «Связаться» (mono 12, accent): opacity за 500ms. Ссылки (телефоны Алексея и Ольги, Instagram) — translateY(25px) и opacity, 550ms, шаг 80ms.
6. Закрытие: слои и панель → translateX(100%), 320ms, cubic-bezier(.5,0,.75,0), затем размонтировать. Закрывается по Esc, по пункту меню (навигация идёт сразу) и при ресайзе ≥960px.

### Главная, коллекция, работа, «Покупателям»
Вёрстку и тексты брать 1:1 из прототипа.
- **Главная:** hero (слово на всю ширину, сетка 3×3 превью), волна-лента названий, строки категорий, блок «Багет», клиенты, отзывы, FAQ.
- **Коллекция:** чипсы категорий, форматы, сортировка, поиск. Сетка `auto-fill minmax(240px,1fr)`, карточки 4/5. <600px — 2 колонки, gap 28px×12px. Вид списком только ≥900px. Кнопка «Показать ещё» (+24).
- **Работа:** sticky-изображение (≥960px), размеры, оформление (холст / багет / стекло), «Добавить в заявку», блоки «следующая работа» и «похожие».
- **Покупателям:** прайс по размерам, шаги, FAQ.
- **Данные:** `CATS`, `FRAMES`, `FAQ`, `STEPS`, `REVIEWS`, `CLIENTS` — константы в скрипте сайта. Каталог — `data/products.json`.

### Заявка (drawer)
- Панель справа шириной min(500px,100%), под ней scrim.
- Открытие: slide-in 600ms. Закрытие: обратная анимация 450ms (.6,0,.3,1).
- Валидация: имя обязательно, в телефоне ≥9 цифр. Ошибки — accent-подчёркивание и текст «Укажите имя и телефон / Укажите имя / Проверьте номер телефона».
- Отправка создаёт заявку со `status: 'new'`, `src: 'Сайт'` (см. модель Request).

### Отзывы (слайдер)
- Автосмена каждые 5s, только когда видно ≥40% блока. Пауза при наведении мыши.
- Свайп больше 40px. Смена слайда — opacity и translateY ±14px.

### Курсор (только pointerType = mouse)
- Accent-круг: 14px, невидим. Над `[data-cursor]` растёт до 96px с подписью «Смотреть» / «Открыть» (12px). Следует за мышью с интерполяцией .2.
- Над `[data-preview]` — плавающее превью min(280px,22vw), квадрат, интерполяция .09, наклон по скорости ±10°.
- **Важно (баг-фиксы):** при скролле без движения мыши заново определять элемент под курсором (`elementFromPoint`). Скрывать курсор при `pointerdown` с touch/pen, при уходе мыши из окна и при blur окна. Включать только при `(any-pointer: fine)`.
- На тач-устройствах (`hover:none`) отключить hover-зум изображений: CSS-`:hover` «залипает» после тапа.

### Прочее
- Появление при скролле: fade + подъём на 24px, .8s, шаг 60ms.
- Волна-лента: SVG textPath по синусоиде, лента accent шириной 60, шрифт 34/700 uppercase, разделитель «✦», скорость 60. Перетаскиванием меняется направление.
- Тема: View Transition, круг раскрывается от точки клика за 750ms (.6,0,.3,1).
- Ссылка в подвале «Вход для сотрудников» → `/admin`.
- **Карта в подвале** («Как нас найти», под телефонами, на всю ширину сетки; по наброску владельца от 16.10.2026 карта справа тянется и вдоль колонок «Галерея» / «Соцсети», они стоят под адресом): адрес, метро в радиусе 2,5 км по прямой (ближние первыми), кнопки «Яндекс Карты» (светлая) / «2ГИС» / «Google Maps». Карта — Яндекс Карты (JS API 3.0, по решению владельца вместо OpenFreeMap прототипа: больше объектов); стиль — оттенки между фоном и текстом подвала (`--inverse` → `--inverse-fg`), акцентное пунктир-перекрестье. Метка «Kuznetsovs Gallery» с пульсирующим кольцом (без него при reduced-motion) — в точке организации на Яндекс Картах (здание и подпись галереи рисует сам Яндекс; закрасить одно здание его API не даёт); пилюли станций метро. Подписи соседей и канала из прототипа не нужны: их показывает сам Яндекс. Зум Яндекса на 1 больше, чем у MapLibre прототипа (тайлы 256 px). Кнопки +, −, «к галерее»; клик по станции (в списке или на карте) показывает её и галерею вместе, наведение подсвечивает пилюлю. Колесо без Ctrl/⌘ листает страницу, на тач — двумя пальцами. Колонки 1fr / 2fr от 900px; карта квадратная <600, 4/3 до 900, дальше на всю высоту левой колонки — адрес и ссылки подвала (min 340px); координаты внизу слева — от 600px. Запуск API и WebGL-карты стоит несколько кадров, поэтому посреди прокрутки он не происходит: за три экрана в первую паузу подгружается скрипт, а сама карта создаётся, когда она на экране и прокрутка остановилась. До этого в рамке заглушка — фон схемы, перекрестье и метка там же, где на карте; карта проявляется под ней (заглушка гаснет за 0.5s).
- **Плашка админа:** показывается, если админ авторизован. Fixed слева снизу, ink-пилюля: «Админка ● N новых».
- На странице работы в плашке ещё «Редактировать KZ-xxx» → `/admin?edit=KZ-xxx`.

## Экраны — админка (`Admin.dc.html`) → `/admin`
### Вход
- Если сессии нет — полноэкранный экран: шапка с логотипом и «← На сайт», заголовок «вход» clamp(64px,10vw,112px).
- Поля «Логин» и «Пароль»: только нижняя линия, шрифт 18px, в фокусе линия accent.
- Переключатель «Запомнить это устройство» (localStorage или sessionStorage), кнопка «Войти», вход по Enter. Ошибки: «Укажите логин», «Неверный пароль».
- **В продакшне:** серверная проверка, роли, rate-limit, logout на сервере.

### Навигация (по ширине окна)
- **≥1024px:** сайдбар 240px, sticky. Пункты-пилюли 15/500, счётчики mono 11. Снизу аватар (инициал в круге 32px), имя, «Выйти», затем «← На сайт» и ThemeToggle.
- **640–1023px:** рейл 88px. Иконка в пилюле 52×30 (активная — ink), подпись 11px, бейдж новых заявок (accent, 18px). Снизу ThemeToggle «icon» и аватар с поповером «На сайт / Выйти».
- **<640px:** sticky top bar (логотип, аватар с поповером, ThemeToggle) и fixed нижний таббар на 5 вкладок с safe-area.
- Отступы контента: снизу 140px; тост поднят на 88px.
- Иконки: layout-dashboard, inbox, image, tag, message-square-quote.

### Разделы
Плотность раскладки зависит от ширины контента (`mw` = окно минус навигация): tier 2 ≥1040, tier 1 ≥600, tier 0 — меньше.

**1. Обзор**
- **Карточки:** 4 KPI («Новые заявки», «В работе», «Выручка за 30 дней», «Средний чек»), тренд к прошлым 30 дням.
  - Колонки: 4 при mw ≥900, иначе 2.
  - При mw <420: шрифт значения 30px, единица «сум» скрыта.
- **Блоки:** «Ждут ответа» (с кнопкой звонка `tel:`), «Ближайшие сроки», «Этапы» (прогресс-бары).
- **График продаж:**
  - метрика: выручка / заказы / средний чек;
  - период: 30 дней (дни) / 3 месяца (недели) / 12 месяцев (месяцы);
  - фильтры: источник, направление;
  - сравнение с прошлым периодом — бар ink-4 с opacity .45;
  - тултип при наведении, ось Y через niceMax.
- **Под графиком:** «Источники», «Направления», «Популярные картины».

**2. Заявки**
- Переключатель «Список / Доска». Поиск по имени, телефону (≥3 цифр), компании, номеру, составу.
- **Список:** колонки зависят от tier, 50 строк + «Показать ещё». Чипсы статусов на tier 0 — одна строка с горизонтальным скроллом.
- **Доска:**
  - 7 колонок статусов, в «Выполнена» и «Отменена» не больше 8 карточек;
  - на мобильном колонка = 100% − 52px со scroll-snap;
  - кнопка «Следующий статус →»;
  - на desktop и планшете — **drag-and-drop** между колонками; колонка-цель подсвечивается paper-3 с inset-рамкой ink; после переноса тост с «Вернуть».
- **Карточка заявки (drawer):**
  - drawer min(620px,100vw); номер, дата, имя;
  - статусы-пилюли, «Отменить заявку»;
  - клиент: имя, компания, телефон, источник; кнопки «Позвонить», «Telegram», «WhatsApp»;
  - состав: размер, оформление, количество, сумма; добавление картины через поиск;
  - срок (date), комментарий клиента, заметки с датой, удаление;
  - сохраняется сразу, с debounce 250ms.

**3. Каталог**
- Чипсы направлений и «Скрытые», поиск, сортировка (как на сайте / код / название / цена). 40 строк + «Показать ещё».
- Чекбоксы для массовых действий: «Показать / Скрыть / Удалить». Sticky ink-пилюля сверху: top 12px, на мобильном 66px.
- Переключатель «на сайте» в строке.
- **Карточка товара (drawer):** превью 4/3, путь к изображению, название, описание, направления-чипсы, размеры (ш×в, цена), «размеры по запросу» через запятую, видимость. Действия: Дублировать, Удалить, Отмена, Сохранить.
- `?edit=KZ-xxx` сразу открывает карточку.

**4. Прайс**
- **«Стандартные размеры»:** новая цена применяется ко всем картинам этого размера с ценой, которая встречается чаще всего. Сохранение по Enter или blur. На tier 0 — 2 колонки, количество под названием.
- **«Изменить все цены»:** процент (чипсы −10/5/10/15/20), округление 1 000 / 5 000 / 10 000, превью 4 размеров «было → стало», кнопка «Применить». Панель sticky, только если обе колонки помещаются (mw ≥892).
- Все изменения с тостом и «Вернуть».

**5. Отзывы**
- Текст (Piazzolla Italic), имя, переключатель «на сайте», вверх/вниз, удалить с «Вернуть». Порядок = порядок в слайдере на сайте.
- На tier 0 кнопки уходят под текст.

**Общее:** тост снизу по центру, 6s, кнопка «Вернуть»; Esc закрывает drawer.

## Экран — 404 (`404.dc.html`)
- **Цифры:** «4 [рама] 4», Onest 600, clamp(132px,30vw,420px), lh .76.
- **Рама** (вместо нуля):
  - .58em × .72em, багет — рамка .03em ink, паспарту paper, холст paper-3 с надписью mono «здесь была страница»;
  - висит на гвозде (точка ink) на тросике (SVG-треугольник, ink-3);
  - за ней «след на обоях» — прямоугольник paper-2 под углом 0°.
- **Физика маятника:** v += (rest − a)·.018; v *= .968. По умолчанию rest = 6°.
  - Тянуть мышью или пальцем: угол от гвоздя, ±40°.
  - Движение мыши рядом подталкивает раму (movementX·.012).
  - reduced-motion: статичный угол.
- **«Поправить раму»:** rest → 0. Через 2200ms соскальзывает на 3–9° (в 20% случаев в другую сторону).
- **Подписи по счётчику** (Piazzolla Italic):
  1. «Ровно! …было.»
  2. «Наверное, гвоздь тоже кривой.»

## Модели данных (сейчас localStorage → перенести в БД)
```ts
Product  { code: string /* KZ-001 */; title: string; description: string; image: string;
           sizes: { w: number; h: number; price: number | null }[]; customSizes: string[];
           categories: ('home'|'kids'|'office'|'public')[]; hidden: boolean; sortOrder: number }
Request  { id; no: number; createdAt; name; phone; company; source: 'Сайт'|'Instagram'|'Telegram'|'Телефон';
           status: 'new'|'contact'|'mockup'|'prod'|'ship'|'done'|'cancel'; comment; due: date | null;
           notes: { at; text }[]; items: { code; title; image; w; h; price | null; frame; qty }[] }
Review   { id; name; text; hidden: boolean; sortOrder: number }
Admin    { id; login; passwordHash; name }
```
- Ключи прототипа: `kz_catalog`, `kz_requests`, `kz_reviews`, `kz_theme`, `kz_route`, `kz_admin_auth`, `kz_admin_tab`.
- В прототипе около 600 сгенерированных выполненных заказов за 2 года для аналитики (`archive()` и `seed()` в Admin). В продакшн их **не переносить**.
- Статусы и подписи: Новая, Связались, Макет, Производство, Доставка, Выполнена, Отменена.
- Оформления: «Холст на подрамнике», «Холст с подрамником + багет», «Бумага в рамке под стеклом».
- При переводе в «Макет» или «Производство» без срока ставится срок +7 дней.

## Как запустить в Claude Code
1. Распакуйте папку, создайте рядом пустой репозиторий и откройте в нём Claude Code.
2. Первый промпт:
```
Прочитай design_handoff_kuznetsovs_gallery/README.md и все *.dc.html в этой папке.
Это hi-fi дизайн-референсы. Собери проект на Next.js 15 (App Router, TypeScript),
стили — CSS Modules с токенами из _ds/.../tokens как CSS-переменными, тёмная тема через [data-theme="dark"].
Этап 1: дизайн-токены, шрифты, layout, шапка (desktop + мобильное staggered-меню), подвал, переключатель темы.
Сверяй каждый экран с прототипом пиксель в пиксель. Покажи план перед кодом.
```
3. Дальше по этапам, по одному промпту на этап:
   1. Главная.
   2. Коллекция и работа.
   3. «Покупателям», заявка, API `POST /api/requests`.
   4. Курсор, анимации, волна.
   5. 404.
   6. Prisma-схема по моделям выше, импорт `products.json`.
   7. Админка: вход, затем разделы по одному.
   8. Плашка админа на сайте и `?edit=`.
4. На каждом этапе открывайте прототип рядом (`npx serve design_handoff_kuznetsovs_gallery`) и просите Claude Code сравнить результат со скриншотами.
